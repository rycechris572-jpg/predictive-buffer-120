# Predictive Buffer 120-tick HUD — cloud build

This source is NOT yet verified to compile or run. A successful GitHub Actions build is needed.

1. Create a new GitHub repository (private is fine).
2. Unzip this archive. Upload the contents of the `Predictive-Buffer-main` folder (including the hidden `.github` folder) to the root of the repository.
3. Commit the files. Go to the Actions tab and open `Build Predictive Buffer (Windows)`.
4. Click `Run workflow` (or open the automatically triggered run).
5. If the build succeeds, download the `predictive-buffer-windows` artifact, unzip it, and use the `.geode` file inside.
6. If it fails, copy the red error message and ask for help fixing it.

Back up the original mod first. The compiled package is intended for Geometry Dash 2.2081 on Windows and Geode compatible with mod.json.
